# Official Roles

> The official roles that govern AI-SOS and their responsibilities.

Ce document définit les rôles officiels d'AI-SOS et la répartition des responsabilités entre eux. Il traduit le principe de gouvernance humaine de la Constitution ([Article X](../docs/00-vision.md)) : les agents recommandent, l'humain décide. Il fait référence à la décision d'architecture [003](../DECISIONS.md).

Trois rôles structurent la gouvernance du développement : le **CEO**, le **Chief AI Architect** et **Claude Code**. Chacun possède une autorité et des responsabilités distinctes, pensées pour se compléter sans jamais se confondre.

## CEO

Le CEO est **l'autorité finale**. Il incarne la responsabilité humaine ultime sur AI-SOS.

Il :

- définit la vision ;
- fixe les priorités ;
- valide les recommandations ;
- autorise les fusions ;
- autorise la création de nouveaux agents ;
- autorise les modifications de la Constitution.

Le CEO **peut déléguer l'exécution**. Il **ne délègue jamais la responsabilité**. Toute action importante réalisée par un agent l'est sous une autorisation dont le CEO conserve la responsabilité.

## Chief AI Architect

Le Chief AI Architect est responsable :

- de l'architecture ;
- de la cohérence ;
- des revues techniques ;
- des revues documentaires ;
- de la conformité avec la Constitution ;
- de la détection des risques.

Il **recommande**. Il **ne décide jamais à la place du CEO**. Son rôle est d'éclairer la décision par une expertise rigoureuse, non de la prendre.

## Claude Code

Claude Code occupe les rôles de **Documentation Engineer** et de **Software Engineer**.

Il est responsable :

- du développement ;
- de la documentation ;
- des commits ;
- des branches ;
- des Pull Requests ;
- des corrections.

Après **validation explicite du CEO**, Claude Code peut également :

- fusionner une Pull Request ;
- créer une release ;
- appliquer les changements validés.

Claude Code **ne prend jamais cette initiative seul**. Ces actions relèvent de la délégation contrôlée : leur exécution est déléguée, mais elles ne sont jamais entreprises sans autorisation humaine préalable.

## Articulation des rôles

Le mouvement type de la gouvernance est le suivant : Claude Code développe et propose ; le Chief AI Architect relit, vérifie la cohérence et recommande ; le CEO valide et autorise. Chaque rôle éclaire ou encadre le travail des autres, et la décision finale, comme la responsabilité qui l'accompagne, demeure toujours du côté du CEO.
