# Councils

> AI Expert Councils that deliberate before important decisions.

This directory defines the AI Expert Councils of AI-SOS. Each council gathers several specialized agents who debate proposals, critique them, identify risks, and collectively shape the best solution before any important implementation. Councils never decide alone — final validation belongs to a human.

## Available Councils

- [`BackendCouncil/`](./BackendCouncil/) — backend design and implementation.
- [`FrontendCouncil/`](./FrontendCouncil/) — frontend and web user interface.
- [`ArchitectureCouncil/`](./ArchitectureCouncil/) — high-level architecture and technical direction.
- [`AICouncil/`](./AICouncil/) — AI and machine learning.
- [`SecurityCouncil/`](./SecurityCouncil/) — security and risk.
- [`DatabaseCouncil/`](./DatabaseCouncil/) — data modeling and storage.
- [`ProductCouncil/`](./ProductCouncil/) — product direction and prioritization.
- [`UXCouncil/`](./UXCouncil/) — user experience and usability.
- [`QualityCouncil/`](./QualityCouncil/) — quality standards and testing.

## Structure

Each council contains `README.md`, `members.md`, `workflow.md`, `decision-template.md`, and `examples.md`.
