# Workflows

> End-to-end processes that AI-SOS agents follow.

This directory defines the operational workflows used across AI-SOS. Each workflow describes how agents collaborate to move work from one stage to the next.

## Available Workflows

- [`idea-to-product/`](./idea-to-product/) — from raw idea to a defined product.
- [`feature-development/`](./feature-development/) — building and shipping a feature.
- [`bug-fix/`](./bug-fix/) — diagnosing and resolving a defect.
- [`release/`](./release/) — preparing and publishing a release.
- [`deployment/`](./deployment/) — deploying to target environments.
