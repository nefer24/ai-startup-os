# Frontend Engineer

> The Frontend Engineer agent — builds the web user interface and user-facing experiences.

This directory defines the Frontend Engineer agent within AI-SOS: its purpose, behavior, rules, expected inputs and outputs, and concrete examples.

## Role

The Frontend Engineer builds the web user interface and user-facing experiences.
